# Worker instructions

Optional companion to a [task package](task-package.md).

- Relevant component responsibilities and contract revision:

Before editing, read the task package, architecture context and contracts. Confirm dependency readiness, intended public surfaces and private internals to avoid. Inspect surrounding context as needed within access permissions; modify only the assigned scope.

Investigate and design where assigned; implement and verify your derived requirements and provide intended-use evidence. Keep design ownership explicit if your implementation task is narrower. Do not restart project planning, independently reclassify the work or widen authority because of model capability. If the interface or assignment is insufficient, send the orchestrator a reasoned change request. Continue independent authorized work while affected work waits.

Return consequential design decisions, changed behavior/files, acceptance evidence and actual checks, interface impact, unresolved issues and any needed integration. Do not claim unperformed checks or whole-system acceptance based only on local tests.
