# Working in this repository

The [ADAC 2.4.0-dev.3 core](releases/2.4.0-dev.3/core.md) defines this candidate method; [capability recommendations](releases/2.4.0-dev.3/recommendations.md) are advisory. Preserve the approved task contract and explicit project pins. This repository describes ADAC; documentation maintenance does not require using ADAC or creating a fictitious product architecture.

Start with requirements and use proportionate practices. For selected ADAC work, the orchestrator owns system understanding, architecture, coordination and the complete result. Component owners retain research/design and integration accountability; bounded workers report to their owner. Shared-interface and cross-component changes reach the orchestrator. Independent reviewers remain read-only.

For substantial engineering or normative method changes, independently review the complete plan and obtain user approval before implementation. After approval, proceed autonomously within the agreement, preserving protected commitments. Return for required contract deltas, not routine internal decisions. Actual permissions and targeted external unblocks still apply.

Preserve immutable snapshots, historical evidence and unrelated work. This revision is method/documentation work: no new demo, live adoption experiment or benchmark; private examples, operational records and historical tooling remain outside the public package. Use existing maintainer checks, which are not adoption prerequisites. Publication and global activation require their own authority.
