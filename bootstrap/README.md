# Start work with ADAC

Give the agent the repository and task using the [README prompt](../README.md#start-with-your-agent). [Setup](../SETUP.md) resolves an exact revision, honors existing pins and separates stable discovery from candidate selection. No method copying, installation or skill is required.

Understand requirements and assess suitability. When ADAC fits authorized work, setup establishes the root `AGENTS.md` entry point and authoritative architecture/delivery records, reusing existing equivalents. This is project knowledge, not installation of ADAC. Read-only evaluation and ordinary local tasks do not require creating these records.

The [new-repository](new-repository.md) and [existing-repository](existing-repository.md) guides explain different starting evidence, not separate methods or gates. The [method index](../method/README.md) routes further reading by activity. Standard templates supply new-record structure; existing equivalent records retain their content and authority.

Before substantial implementation, the complete plan includes requirements, functional/software architecture, interfaces, owners, necessary investigation, dependencies, parallel sequencing and evidence. Independently review it and obtain initial user approval. Afterward continue autonomously through correction and required final review. Workers report to owners; owners coordinate shared changes with the orchestrator. No amount of documentation alone proves approval or completion.
