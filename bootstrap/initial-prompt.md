# A repository link and a task

Use the canonical prompt in the [README](../README.md#start-with-your-agent). It honors an existing project pin and otherwise selects the latest stable release. Development candidates require explicit selection; migrating an existing pin requires explicit authority.

The agent follows [SETUP.md](../SETUP.md), retrieves actual documents at one commit and assesses suitability. If ADAC applies, it establishes the project entry point and records and uses the [method index](../method/README.md) for applicable explanations. A user need not choose templates or install a skill.

The core defines required approval and review; reading the method does not itself authorize product implementation. The method can remain in its source repository while architectural and delivery knowledge belongs to the project. Copying the method for local or customized use preserves its source revision and identified adaptations.
